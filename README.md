## Профиль в трёх абзацах

Свожу теорию и бизнес в работающее решение. Сильная сторона — не глубина одной архитектуры, а сборка целого: рассматриваю систему целиком и собираю из кусочков (математика, механика домена, код, бизнес-задача) работающую картину. Беру задачи, под которые нет готового эксперта: baseline за пару недель, дальше итеративная докрутка с бизнесом.

Один человек — несколько ролей: ML + инженерия/MLOps + full-cycle в одном. Инженерная дисциплина сквозная: Puppet и Jenkins в НИИ ТП, Airflow в Rambler, CI/CD в JungleJobs, MLOps-пайплайн с one-click деплоем в Delimobil.

Охват доменов как доказательство переносимого метода: causal-аналитика, A/B-эксперименты, ML/CV/NLP, ranking, uplift, LLM-агенты, MLOps. Широкие роли (несколько направлений, ownership) — осознанное предпочтение, а не отсутствие фокуса.
