# JungleJobs · апрель 2018 — декабрь 2019

**Разработчик, отдел машинного обучения**, проект sever.ai — ML-скоринг кандидатов для HR.
junglejobs.ru

Стартап-стадия: до моего прихода в DS-отделе был один академический DS, рядом — команда разработки с общими наработками. С декабря 2019 — продолжение работы в той же команде после перевода направления к стратегическому инвестору ([Talenttech](04-talenttech.md)).

## Что делал

Поднял с нуля инженерную инфраструктуру DS-команды:

- Async web-сервис скоринга на aiohttp.
- Фоновые задачи на Celery; хранилища PostgreSQL + MongoDB.
- CI/CD-пайплайн (Jenkins), деплой через Ansible + Docker.
- Логирование в ELK, JupyterHub для команды DS.

Участвовал в разработке моделей скоринга кандидатов:

- Скоринг резюме — в проде.
- Скоринг видеоинтервью.

## Стек

Python, aiohttp, Celery, PostgreSQL, MongoDB, Ansible, Docker, Jenkins, ELK, sklearn, bigartm, PyTorch.
