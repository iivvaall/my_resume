Отдел вёл песочницу для детонации подозрительных файлов: по заданию поднимается виртуалка, туда закидывается образец, запускается, наружу стримятся логи. Работа на стыке разработки и администрирования: кодирование, фикс багов, участие в архитектурных решениях.

## Что делал

- Инструментарий управления VM-образами через libvirt: запуск образа, выполнение команды внутри, снятие диффа диска и запись в git LFS (версионирование состояний образа).
- Настроил перехват HTTPS-трафика песочницы: интеграция opensource MITM-прокси — iptables-редиректы трафика на прокси + установка корневого сертификата (CA) в доверенные на образе. Сам прокси — готовый opensource; моя часть — сетевая и административная интеграция.
- Асинхронность/конкурентность на gevent.

## Стек

Python 2.6/3.6, Linux, libvirt, gevent, git LFS, iptables.
