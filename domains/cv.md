# Домен: Computer Vision

## Ключевые кейсы

### 1. Проверка фотографий при завершении аренды (Delimobil, прод, on-device)

Флагманский кейс: YOLOv8n-seg → TFLite on-device, CI с численной сверкой модели между Python и мобилкой, синтетика для разрушения shortcut learning, причинная оценка бизнес-эффекта (−46% «обходных» аренд, ~50 млн ₽/год). Полное описание — [projects/photo-check-on-device.md](../projects/photo-check-on-device.md).

### 2. Классификаторы состояния машин (Delimobil, прод)

Единый самописный движок обучения классификаторов (timm, DI-контейнеры) и семейство голов: грязная/чистая машина, релевантность фото, стороны машины. Взвешенный CE + label smoothing, температурная калибровка (запекается в forward при экспорте), метрики с доверительными интервалами по фолдам, Optuna с консервативной целью (min ROC-AUC по фолдам), GroupKFold по vehicle_id. В проде: модель грязи (ROC-AUC 0.87) и модель релевантности (3 класса, acc 0.98, + TFLite-версия для мобилки). Используется в [приоритизации моек](../projects/wash-prioritization.md).

### 3. Zero-shot VLM на повреждениях (Delimobil, исследование)

Eval-харнесс Qwen3-VL-235B на 7042 фото повреждений — [projects/damages-vlm.md](../projects/damages-vlm.md).

### 4. Детекция повреждений — кейс управления рамкой (Delimobil)

Бизнес хотел заменить модераторов CV-моделью. Метрики упёрлись: точность 80–90% для «заменить модерацию» неприемлема, серая зона огромная. Не дожимал мёртвую метрику: спустился к процессу модерации, достроил аналитику, переформулировал задачу с «заменить» на «ускорить модерацию» — в этой рамке нашёлся реализуемый инкремент (модели определения ракурса фото), который катим в прод. Кейс про границу применимости ML, а не про архитектуру.

### 5. Детекция фирменной атрибутики на одежде (TalentTech)

Полный цикл сам: постановка задачи на разметку, обучение детектора.

### 6. «Эмоциональное напряжение» по видео (TalentTech)

Кейс честной валидации: по задумке — предсказание BigFive, но валидация показала, что модель ловит не целевой конструкт. Разобрались, что детектится, переназвали рабочим термином «эмоциональное напряжение», не стали продавать как BigFive.

### 7. Геометрия таблиц через shapely (Delimobil)

Не «картиночный» CV, но геометрический: реконструкция табличной сетки из векторных PDF-примитивов — полигоны ячеек из распознанных линий, распределение текста по ячейкам. → [projects/spare-pdf-parsing.md](../projects/spare-pdf-parsing.md)

## Инструментарий — статус по факту

| Тема | Статус |
|---|---|
| PyTorch | Уверенно: кастомные лоссы, модули, свой train loop; lightning пробовал |
| ultralytics | В проде (сегментация). Вокруг библиотеки своё: сборка датасета с синтетикой, кастомный eval. Внутрь библиотеки не лез |
| timm | В проде (классификаторы, свой движок обучения поверх) |
| Аугментации | torchvision transforms + albumentations |
| TFLite | Прод-экспорт (ai_edge_torch) + CI с численной сверкой |
| OpenCV | Утилитарно: загрузка/обработка видео, перспективное преобразование. Не «классический CV в глубину» |
| shapely | С артефактом: восстановление структуры сложных таблиц |
| Разметка | Ставил задачи командам разметки; сам размечал сегментацию (CVAT + SAM) |
| VLM | Есть артефакт: zero-shot eval на 7k фото (см. кейс 3) |
| ONNX | Пробовал, в прод не пошло (совместимость библиотек) |
| Квантизация, TensorRT / RKNN / OpenVino, mmdet | Опыта нет |

## Serving и latency

- Двухуровневая инференс-платформа: FastAPI-фронт + TorchServe (CPU/GPU), батчинг per-model, Prometheus; нагрузочное профилирование и подбор параметров сервинга. → [projects/inference-platform.md](../projects/inference-platform.md)
- Точечный latency-кейс: синхронная серверная обёртка фильтрации фото с бюджетом ответа 1 секунда, поведение give-up без retry под latency-бюджет, нагрузочное тестирование. (Это синхронный сервис под SLA, не потоковый видео-инференс с парка камер.)
- On-device: TFLite в мобильном приложении, препроцессинг зашит в граф модели.

## Границы опыта (честно)

- Основной прод-опыт — классификация/сегментация фото; потоковое видео и real-time GPU-инференс с камер — нет.
- Квантизацию и специализированные рантаймы (TensorRT и т.п.) не делал — деплой-таргеты были CPU/GPU TorchServe и TFLite on-device.
