# Zero-shot VLM на повреждениях автомобилей (Delimobil, исследование)

Проверка применимости VLM как замены детектора повреждений: eval-харнесс zero-shot **Qwen3-VL-235B** через OpenAI-совместимый API на **7042 размеченных фото** повреждений (полная CVAT-разметка).

## Постановка

- Пайплайн: индексация разметки → предсказание → eval → демо (DVC); ресайз long-side 2048.
- Промпт со строгим JSON-выходом `{bbox, part, type, description}` по 10 классам дефектов; bbox в [0..1000]; T=0.2; 16 параллельных воркеров; кэш предсказаний для resume.
- Метрика: IoU-метчинг предсказаний с gold-разметкой @ IoU 0.5.

## Результат

- macro-F1 **0.375**, macro-precision 0.456, macro-recall 0.376; mean IoU matched **0.75**.
- Вывод: как замена обученного детектора zero-shot VLM пока слаб (F1 0.38), но локализация того, что модель находит, приличная (IoU 0.75). Исследовательский baseline, не в проде.

## Границы вклада — и почему это отдельный кейс

Реализацию делал LLM-агент (Claude) под моей постановкой и ревью; приёмка — по метрикам eval. Артефакт закрывает сразу две темы: применимость VLM на реальной задаче (с цифрами) и **agentic-инжиниринг** — реальная задача, делегированная агенту целиком, с приёмкой по eval. Глагол честный: «поставил задачу и принял результат», не «написал руками».
