# spare — парсинг заказ-нарядов (Delimobil)

Разовая выгрузка структурированных данных из PDF заказ-нарядов контрагентов для аналитики затрат на материалы. Таблицы сложные — готовые парсеры (camelot и т.п.) не справлялись; собран собственный пайплайн.

## Геометрия: реконструкция табличной сетки

- Разбор векторных PDF-примитивов: pdfminer + pdfplumber.
- **shapely** (STRtree, union/difference, buffer) — сборка полигонов ячеек из распознанных линий, распределение текста по ячейкам.
- Собственный алгоритм refine линий: взвешенное по длине слияние коллинеарных отрезков + snap концов через `np.searchsorted`; карта инцидентности достраивает недостающие линии сетки; эвристика удаления штрихкода.

## Семантика: «грамматика документа»

Парсер-комбинаторы (funcparserlib): геометрия → поток токенов → regexp-теги → грамматика с 5 альтернативными layout-версиями документа.

## Инженерия

DVC-пайплайн, `multiprocessing.Pool`, golden-тесты на реальных документах, GitLab CI + Docker, выгрузка parquet/xlsx, матчинг номенклатуры с Vertica.
