# Приоритизация машин на мойку (Delimobil, прод)

Operations-задача: какие машины парка отправлять на мойку в первую очередь.

## Решение

- Logreg по клиентским отзывам (сигнал «машина грязная» из [классификации тематик отзывов](nps-text-classification.md)).
- Дополнен **CV-score по фотографиям**: классификатор «грязная/чистая» (efficientnet-b0, ROC-AUC 0.87 на GroupKFold по vehicle_id) из единого движка классификаторов состояния машин.
- В движке: взвешенный CE + label smoothing, температурная калибровка (запекается в forward при экспорте), Optuna, метрики с доверительными интервалами по фолдам.

## Статус

В проде. Пример прагматичной комбинации: простая интерпретируемая модель на текстовом сигнале + CV там, где текста нет.
